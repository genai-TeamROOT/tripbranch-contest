# 후속 질문 제안 Unit Evals

한 턴(사용자 발화 + 답변 + 노출된 장소)을 넣고 나온 제안 문구를 확인하는 단일 턴 평가
자산을 둡니다.

이 슬롯에서 확인할 것은 문장 품질보다 **범위**입니다. 개수·길이·중복은
`follow_up_suggester.py`가 코드로 걸러내므로 회귀로 이미 잡히고, 여기서 봐야 하는 것은
`capability_rules.md`의 "할 수 없는 일"(예약·결제·길찾기·해외)이 제안으로 새어나오는지,
그리고 이번 턴에 없던 장소 이름을 지어내는지입니다 — 둘 다 코드로는 거를 수 없습니다.

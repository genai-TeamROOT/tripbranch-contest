# closure 평가

## 무엇을 재나

정답이 하나인 분류입니다 — 원문에 적힌 것을 옮기는 일이라 지어낼 여지가 없어야
합니다. 그래서 정확도보다 **틀리는 방향**을 봅니다.

| 축 | 보는 것 | 왜 |
|---|---|---|
| **거짓 양성** | 안 쉬는 요일을 쉰다고 담는가 | 멀쩡한 장소가 그날 통째로 사라진다 |
| 거짓 음성 | 쉬는 요일을 놓치는가 | 휴무일에 추천이 나간다 |
| 부정 표현 | `제외`·`개관하되`를 뒤집는가 | 거짓 양성 중 가장 위험한 갈래 |
| 주기 구분 | `월 1회`를 매주로 담는가 | 안 쉬는 3주에 후보가 사라진다 |

**거짓 양성이 거짓 음성보다 나쁩니다.** 놓치면 사용자가 헛걸음하지만, 잘못 담으면
그 장소가 아예 안 보입니다.

## 표본

실제로 만나는 입력으로 재는 것이 아닙니다. 부정·예외 24종은 따로 셉니다.

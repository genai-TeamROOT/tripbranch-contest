# mode_judge 평가

## 무엇을 재나

이 슬롯은 "정답이 하나"인 분류가 아닙니다. 같은 구간을 걸어도 되고 타도 되는 경우가
많아, 정확도보다 **조건에 반응하는가**와 **근거 없이 흔들리지 않는가**를 봅니다.

| 축 | 보는 것 |
|---|---|
| 무반응 | 맑고 동행·무장애 조건이 없을 때 기존 규칙과 같은 판정을 내는가 |
| 반응 | 같은 구간에 비를 얹으면 전환이 늘어나는가 |
| 맥락 | 같은 조건에서 뒤 구간이 앞 구간보다 쉽게 전환되는가 |
| 일관 | 같은 거리·조건이면 일정과 추천이 같은 수단을 말하는가 |
| 보호 | 도보·자동차를 명시한 요청에서 이 슬롯이 아예 안 불리는가 |

## 표본

`backend/test_results/`에 원자료를 남기고 `HISTORY.md`에 요약 표를 옮깁니다.
표본은 실제 LLM이 뽑은 조건으로 만듭니다 — 사람이 손으로 지은 조건으로 재면
시스템이 만들지 않는 입력으로 재는 것이 됩니다.

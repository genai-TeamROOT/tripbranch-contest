유모차(stroller_access)는 휠체어 값을 그대로 씁니다. 둘이 갈리는 지점이 흙·자갈길 정도라 따로 매길 값어치가 작습니다. 휠체어 기준이 유모차에 보수적이라 못 가는 곳을 주지는 않습니다. 흙길만 나중에 따로 손봅니다.

가능어떤 경로로든 주요 공간에 들어갈 수 있다. 보조출입구·후문·지하주차장 입구·엘리베이터·리프트를 쓰거나, 돌아 들어가야 해도 여기다.
예) 주출입구는 단차가 있으나 보조출입구는 턱이 없어 접근 가능함 / 1층과 지하1층 사이에 계단이 있으나 엘리베이터 이용 가능 / 흙구간 있음
부분들어가긴 하는데 일부 공간에 못 간다.
예) 외부관람은 가능하나 미술관 출입은 불가능함 / 팔각정은 접근 불가
불가주요 공간에 못 들어간다.
예) 출입통로가 좁아 휠체어 진입 어려움 / 턱이 있어 접근 불가능한 구간 있음 / 계단뿐이고 엘리베이터·리프트 없음

엘리베이터와 에스컬레이터는 다릅니다. 엘리베이터(89문장)는 휠체어가 탈 수 있어 가능이고, 에스컬레이터(5문장)는 못 탑니다.
단어가 아니라 문장 전체로 판단합니다. 흙이 들어갔다고 일괄 처리하지 않되, 경사·계단이 함께 붙으면 다릅니다.

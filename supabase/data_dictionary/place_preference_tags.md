# place_preference_tags 데이터 딕셔너리

## 개요

`public.place_preference_tags`는 Google 리뷰와 Naver 블로그에서 추출한 장소별 취향 태그를 저장합니다. 같은 문서에서 같은 태그가 반복돼도 태그별로 한 번만 집계합니다.

| 필드 | 타입 | NULL 허용 | 정의 | 값 예시 | 활용 예시 |
| --- | --- | --- | --- | --- | --- |
| `content_id` | text | 아니오 | `places.content_id`와 같은 장소 식별자입니다. | `126499` | 추천 장소와 태그를 연결합니다. |
| `preference_code` | text | 아니오 | 프로그램에서 사용하는 취향 코드입니다. | `quiet` | 다국어 라벨 변환과 태그별 집계에 사용합니다. |
| `preference_label` | text | 아니오 | 사용자 화면에 표시할 문구입니다. | `조용히 머물기 좋은` | 추천 카드에 표시합니다. |
| `display_rank` | smallint | 아니오 | 장소 안에서 태그를 보여줄 우선순위입니다. | `1` | 상위 태그를 일정한 순서로 표시합니다. |
| `mention_count` | integer | 아니오 | 해당 태그를 언급한 문서 수입니다. 문서 하나당 최대 1회입니다. | `12` | 카드에 `12건`으로 표시합니다. |
| `positive_document_count` | integer | 아니오 | 긍정 문맥으로 판정된 문서 수입니다. | `10` | 기존 추출 규칙을 검토합니다. |
| `negative_document_count` | integer | 아니오 | 부정 문맥으로 판정된 문서 수입니다. | `2` | 상반된 후기가 많은 태그를 점검합니다. |
| `source_count` | smallint | 아니오 | 태그가 발견된 출처 유형 수입니다. | `2` | Google·Naver 양쪽 언급 여부를 판단합니다. |
| `confidence` | numeric(5,4) | 예 | 기존 규칙이 계산한 태그 신뢰도입니다. | `0.8333` | 추출 규칙 비교와 운영자 검토에 사용합니다. |
| `extraction_version` | text | 아니오 | 취향 추출 규칙·사전 버전입니다. | `preference-v1` | 재추출 결과를 구분합니다. |
| `created_at` | timestamptz | 아니오 | 최초 적재 시각입니다. | `2026-08-29T01:00:00+09:00` | 적재 시점을 확인합니다. |
| `updated_at` | timestamptz | 아니오 | 마지막 갱신 시각입니다. | `2026-08-29T01:00:00+09:00` | 갱신 여부를 확인합니다. |

## 사용 시 유의사항

- `mention_count`는 단어 출현 횟수가 아니라 문서 수입니다.
- 현재 용산구·성동구 데이터는 기존 긍정 조건으로 선택된 상위 태그입니다.
- 이후 지역은 긍정 비율을 선택 조건으로 사용하지 않고 문서 언급 수 중심으로 생성합니다.
- 리뷰 원문은 이 테이블에 저장하지 않으며, 추후 근거 테이블로 별도 적재할 수 있습니다.

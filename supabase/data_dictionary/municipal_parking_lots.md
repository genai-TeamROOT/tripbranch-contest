# municipal_parking_lots 데이터 딕셔너리

## 개요

`public.municipal_parking_lots`는 서울시 시영·공영주차장 실시간 API(`GetParkingInfo`)의 주차장 코드를 기준으로, 주소와 좌표 등 변하지 않는 기본 정보를 저장하는 카탈로그입니다(D-101). `GetParkingInfo`는 실시간 주차 대수는 제공하지만 좌표를 제공하지 않으므로, 동기화 작업이 주소를 한 번 지오코딩해 이 테이블에 저장합니다.

이 테이블은 실시간 현황 저장소가 아닙니다. 현재 주차 대수·가능 주차 대수·기준 시각은 사용자가 질문할 때마다 `GetParkingInfo`에서 다시 조회합니다. 따라서 이 테이블을 통해 거리순으로 정렬할 수 있고, 실제 빈자리 정보는 최신 API 응답으로 안내합니다.

| 필드 | 타입 | NULL 허용 | 정의 | 값 예시 | 활용 예시 |
| --- | --- | --- | --- | --- | --- |
| `parking_code` | text | 아니오 | 서울시 `GetParkingInfo`의 주차장 식별 코드(`PKLT_CD`)입니다. PK이며 동기화 upsert 기준입니다. | `110001` | API에서 받은 실시간 현황과 카탈로그의 주소·좌표를 결합합니다. |
| `name` | text | 아니오 | 주차장 이름입니다. | `세종로 공영주차장(시)` | 사용자에게 주차장 후보 이름으로 보여줍니다. |
| `address` | text | 예 | 주차장 주소입니다. API 원문에서 확보하거나 동기화 과정에서 보강합니다. | `서울특별시 종로구 세종대로 175` | 카드에 주소를 표시하고, 좌표가 없을 때 재지오코딩 기준으로 사용합니다. |
| `district` | text | 예 | 주차장이 속한 자치구명입니다. | `종로구` | 사용자가 "종로구 공영주차장"처럼 구 단위로 물을 때 카탈로그를 빠르게 찾습니다. |
| `latitude` | double precision | 예 | 한 번 지오코딩해 저장한 위도(WGS84)입니다. | `37.5759` | 사용자 위치·명소 좌표에서 주차장까지 거리를 계산하고 가까운 순으로 정렬합니다. |
| `longitude` | double precision | 예 | 한 번 지오코딩해 저장한 경도(WGS84)입니다. | `126.9769` | 위도와 함께 거리 계산에 사용합니다. |
| `capacity` | integer | 예 | 주차장 총 주차 가능 대수입니다. 정적 카탈로그 값이라 실시간 잔여 대수와 다릅니다. | `1260` | API 응답에 총 대수가 비어 있을 때 보조 정보로 표시합니다. |
| `paid` | boolean | 예 | 유료 여부입니다. `true`는 유료, `false`는 무료, `NULL`은 정보 미제공입니다. | `true` | 주차장 카드에 유료·무료 정보를 표시합니다. |
| `updated_at` | timestamptz | 아니오 | 카탈로그 행이 마지막으로 동기화된 시각입니다. 기본값은 `now()`입니다. | `2026-08-27T12:00:00+09:00` | 주소·좌표 등 정적 정보의 갱신 시점을 확인합니다. |

## 인덱스·접근 정책

- PK: `parking_code`
- `municipal_parking_lots_district_idx`: `district` 기준 구 단위 조회를 빠르게 합니다.
- `municipal_parking_lots_coordinates_idx`: 좌표가 있는 행만 대상으로 `(latitude, longitude)`를 인덱싱합니다.
- RLS가 활성화되어 있고 anon/authenticated 정책은 없습니다. FastAPI 서버의 `service_role`(Secret Key)만 동기화·조회합니다.

## 사용 시 유의사항

- 이 테이블에 없는 주차장이라고 해서 실시간 주차 API에 없는 것은 아닙니다. 카탈로그 동기화 전이거나 주소·좌표 보강이 아직 안 된 경우일 수 있으며, 이때도 API의 구 단위 현황은 답할 수 있지만 거리 정렬은 생략됩니다.
- `capacity`는 카탈로그 보조값입니다. 사용자에게 "현재 n대 가능"처럼 실시간으로 안내할 값은 `GetParkingInfo`에서 받은 총 대수와 현재 주차 대수로 계산해야 합니다.
- 서울시 `GetParkingInfo`는 시영·공영주차장 중심입니다. 민영을 포함한 "근처 주차장" 탐색은 서울시 실시간 도시데이터의 별도 경로를 사용합니다.
